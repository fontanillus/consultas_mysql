JARDÍN

16 ejercicios de consultas simples en MySQL.

Descargar jardineria.sql

Ejercicios

Abre un enunciado para ver su SQL.

1. Devuelve un listado con el código de oficina y la ciudad donde hay oficinas.
MySQL 
SELECT pk_oficina, ciudad
FROM oficina;
2. Devuelve un listado con la ciudad y el teléfono de las oficinas de España.
MySQL 
SELECT ciudad, telefono
FROM oficina
WHERE pais = 'España';
3. Devuelve un listado con el nombre, apellidos y email de los empleados cuyo jefe tiene un código igual a 7.
MySQL 
SELECT nombre, apellido1, apellido2, email
FROM empleado
WHERE fk_jefe = 7;
4. Devuelve el nombre del puesto, nombre, apellidos y email del jefe de la empresa.
MySQL 
SELECT puesto, nombre, apellido1, apellido2, email
FROM empleado
WHERE fk_jefe IS NULL;
5. Devuelve un listado con el nombre, apellidos y puesto de aquellos empleados que no sean representantes de ventas.
MySQL 
SELECT nombre, apellido1, apellido2, puesto
FROM empleado
WHERE puesto <> 'Representante Ventas';
6. Devuelve un listado con el nombre de todos los clientes españoles.
MySQL 
SELECT nombre_cliente
FROM cliente
WHERE pais = 'Spain';
7. Devuelve un listado con los distintos estados por los que puede pasar un pedido.
MySQL 
SELECT DISTINCT estado
FROM pedido;
8. Devuelve un listado con el código de cliente de aquellos clientes que realizaron algún pago en 2008, sin mostrar códigos repetidos.
8A. Utilizando la función YEAR de MySQL. 
SELECT DISTINCT fk_cliente
FROM pago
WHERE YEAR(fecha_pago) = 2008;
8B. Utilizando la función DATE_FORMAT de MySQL. 
SELECT DISTINCT fk_cliente
FROM pago
WHERE DATE_FORMAT(fecha_pago, '%Y') = '2008';
8C. Sin utilizar YEAR ni DATE_FORMAT. 
SELECT DISTINCT fk_cliente
FROM pago
WHERE fecha_pago BETWEEN '2008-01-01' AND '2008-12-31';
9. Devuelve un listado con el código de pedido, código de cliente, fecha esperada y fecha de entrega de los pedidos que no han sido entregados a tiempo.
MySQL 
SELECT pk_pedido, fk_cliente, fecha_esperada, fecha_entrega
FROM pedido
WHERE fecha_esperada < fecha_entrega;
10. Devuelve un listado con el código de pedido, código de cliente, fecha esperada y fecha de entrega de los pedidos entregados al menos dos días antes de la fecha esperada.
10A. Utilizando la función ADDDATE de MySQL. 
SELECT pk_pedido, fk_cliente, fecha_esperada, fecha_entrega
FROM pedido
WHERE ADDDATE(fecha_entrega, 2) <= fecha_esperada;
10B. Utilizando la función DATEDIFF de MySQL. 
SELECT pk_pedido, fk_cliente, fecha_esperada, fecha_entrega
FROM pedido
WHERE DATEDIFF(fecha_esperada, fecha_entrega) >= 2;
10C. Utilizando el operador de resta -. 
SELECT pk_pedido, fk_cliente, fecha_esperada, fecha_entrega
FROM pedido
WHERE fecha_esperada - INTERVAL 2 DAY >= fecha_entrega;
11. Devuelve un listado de todos los pedidos que fueron rechazados en 2009.
MySQL 
SELECT *
FROM pedido
WHERE estado = 'Rechazado'
    AND YEAR(fecha_pedido) = 2009;
12. Devuelve un listado de todos los pedidos que han sido entregados en el mes de enero de cualquier año.
MySQL 
SELECT *
FROM pedido
WHERE estado = 'Entregado'
    AND MONTH(fecha_entrega) = 1;
13. Devuelve un listado con todos los pagos que se realizaron en el año 2008 mediante PayPal. Ordena el resultado de mayor a menor.
MySQL 
SELECT *
FROM pago
WHERE YEAR(fecha_pago) = 2008
    AND forma_pago = 'PayPal'
ORDER BY total DESC;
14. Devuelve un listado con todas las formas de pago que aparecen en la tabla pago. No deben aparecer formas de pago repetidas.
MySQL 
SELECT DISTINCT forma_pago
FROM pago;
15. Devuelve un listado con todos los productos que pertenecen a la gama Ornamentales y que tienen más de 100 unidades en stock. Ordena el resultado por su precio de venta de mayor a menor.
MySQL 
SELECT *
FROM producto
WHERE fk_gama = 5
    AND cantidad_en_stock > 100
ORDER BY precio_venta DESC;
16. Devuelve un listado con todos los clientes que sean de la ciudad de Madrid y cuyo representante de ventas tenga el código 11 o 30.
16A. Utilizando IN. 
SELECT *
FROM cliente
WHERE ciudad = 'Madrid'
    AND fk_representante_ventas IN (11, 30);
16B. Utilizando OR. 
SELECT *
FROM cliente
WHERE ciudad = 'Madrid'
    AND (fk_representante_ventas = 11
         OR fk_representante_ventas = 30);
