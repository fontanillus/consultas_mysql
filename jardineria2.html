Ejercicios

1. Obtén un listado con el nombre de cada cliente y el nombre y apellido de su representante de ventas.

Une cada cliente con su representante y muestra el nombre y el primer apellido de este.

Tablas y relaciones (FK → PK)

  • cliente.fk_representante_ventas → empleado.pk_empleado
MySQL 
SELECT
    c.nombre_cliente,
    e.nombre,
    e.apellido1
FROM cliente AS c
INNER JOIN empleado AS e
    ON c.fk_representante_ventas = e.pk_empleado;
2. Muestra el nombre de los clientes que hayan realizado pagos junto con el nombre de sus representantes de ventas.

INNER JOIN exige un pago asociado. DISTINCT elimina las filas repetidas cuando hay varios pagos.

Tablas y relaciones (FK → PK)

  • cliente.fk_representante_ventas → empleado.pk_empleado
  • pago.fk_cliente → cliente.pk_cliente
MySQL 
SELECT DISTINCT
    c.nombre_cliente,
    e.nombre,
    e.apellido1
FROM cliente AS c
INNER JOIN empleado AS e
    ON c.fk_representante_ventas = e.pk_empleado
INNER JOIN pago AS p
    ON c.pk_cliente = p.fk_cliente;
3. Muestra el nombre de los clientes que no hayan realizado pagos junto con el nombre de sus representantes de ventas.

LEFT JOIN conserva clientes con representante aunque carezcan de pagos. IS NULL selecciona esos clientes.

Tablas y relaciones (FK → PK)

  • cliente.fk_representante_ventas → empleado.pk_empleado
  • pago.fk_cliente → cliente.pk_cliente
MySQL 
SELECT
    c.nombre_cliente,
    e.nombre,
    e.apellido1

Un SELF JOIN relaciona una tabla consigo misma mediante distintos alias. Aquí e identifica al empleado y j a su jefe. LEFT JOIN conserva a los empleados sin jefe.

9. Devuelve el nombre de los clientes a los que no se les ha entregado a tiempo un pedido.

Se seleccionan los pedidos entregados después de la fecha esperada. DISTINCT elimina los nombres repetidos.

Tablas y relaciones (FK → PK)

  • pedido.fk_cliente → cliente.pk_cliente
MySQL 
SELECT DISTINCT
    c.nombre_cliente
FROM cliente AS c
INNER JOIN pedido AS p
    ON c.pk_cliente = p.fk_cliente
WHERE p.fecha_entrega > p.fecha_esperada;
10. Devuelve un listado de las diferentes gamas de producto que ha comprado cada cliente.

Los INNER JOIN recorren pedidos, detalles, productos y gamas. DISTINCT elimina las combinaciones repetidas de nombre y gama.

Tablas y relaciones (FK → PK)

  • pedido.fk_cliente → cliente.pk_cliente
  • detalle_pedido.fk_pedido → pedido.pk_pedido
  • detalle_pedido.fk_producto → producto.pk_producto
  • producto.fk_gama → gama_producto.pk_gama
MySQL 
SELECT DISTINCT -- Evitamos repetir la misma gama para un mismo cliente.
    c.nombre_cliente,   -- Nombre del cliente.
    g.gama              -- Nombre de la gama de productos.
FROM cliente AS c       -- Empezamos por la tabla de clientes.
INNER JOIN pedido AS pe
    -- Relacionamos cada cliente con sus pedidos.
    ON c.pk_cliente = pe.fk_cliente
INNER JOIN detalle_pedido AS dp
    -- Buscamos los productos incluidos en cada pedido.
    ON pe.pk_pedido = dp.fk_pedido
INNER JOIN producto AS pr
    -- Identificamos cada producto mediante su código.
    ON dp.fk_producto = pr.pk_producto
INNER JOIN gama_producto AS g
    -- Averiguamos a qué gama pertenece cada producto.
    ON pr.fk_gama = g.pk_gama;

18. Devuelve un listado de los productos que nunca han aparecido en un pedido.

LEFT JOIN busca cada producto en las líneas de pedido. IS NULL selecciona los productos ausentes.

Tablas y relaciones (FK → PK)

  • detalle_pedido.fk_producto → producto.pk_producto
MySQL 
SELECT
    p.pk_producto,
    p.nombre
FROM producto AS p 
-- Conservamos todos los productos.
LEFT JOIN detalle_pedido AS dp 
-- Relacionamos la PK con la FK.
    ON p.pk_producto = dp.fk_producto
-- Seleccionamos los productos que nunca se han pedido.
WHERE dp.fk_producto IS NULL;

22. Devuelve un listado con los datos de los empleados que no tienen clientes asociados y el nombre de su jefe asociado.

Un SELF JOIN relaciona una tabla consigo misma mediante distintos alias. Aquí e identifica al empleado y j a su jefe. El otro LEFT JOIN permite seleccionar a los empleados sin clientes.

Tablas y relaciones (FK → PK)

  • cliente.fk_representante_ventas → empleado.pk_empleado
  • empleado.fk_jefe → empleado.pk_empleado
MySQL 
SELECT
    e.pk_empleado,
    e.nombre,
    e.apellido1,
    e.apellido2,
    j.nombre AS nombre_jefe
FROM empleado AS e
LEFT JOIN cliente AS c
    ON e.pk_empleado = c.fk_representante_ventas
LEFT JOIN empleado AS j
    ON e.fk_jefe = j.pk_empleado
WHERE c.pk_cliente IS NULL;
