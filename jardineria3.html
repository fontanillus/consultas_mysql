Ejercicios

1. Crear una vista llamada pedidos_no_entregados que muestre el código del pedido, la fecha del pedido, el nombre completo del cliente y el estado. Mostrar únicamente los pedidos no entregados. Ordenar por estado.

Base de datos jardineria3

INNER JOIN vincula cada pedido con su cliente. El filtro excluye el estado Entregado y ORDER BY ordena por estado.

MySQL 
CREATE OR REPLACE VIEW pedidos_no_entregados AS
SELECT
    p.pk_pedido AS codigo_pedido,
    p.fecha_pedido,
    CONCAT(
    c.nombre_cliente, ' - ',
    c.nombre_contacto, ' ',
    c.apellido_contacto
) AS nombre_completo,
    p.estado
FROM pedido AS p
INNER JOIN cliente AS c
    ON p.fk_cliente = c.pk_cliente
WHERE p.estado <> 'Entregado'
ORDER BY p.estado ASC;

-- Verificación de la vista
SELECT *
FROM pedidos_no_entregados;
2. Crear una vista llamada listado_pagos_clientes. Mostrar todos los clientes y sus pagos. Columnas: nombre y apellidos concatenados, teléfono, ciudad, país, fecha_pago, total del pago e id de la transacción.

Base de datos jardineria3

LEFT JOIN conserva a todos los clientes. Las columnas del pago contienen NULL cuando el cliente carece de pagos.

MySQL 
CREATE OR REPLACE VIEW listado_pagos_clientes AS
SELECT
    CONCAT(
        c.nombre_cliente, ' - ',
        c.nombre_contacto, ' ',
        c.apellido_contacto
    ) AS nombre_completo,
    c.telefono,
    c.ciudad,
    c.pais,
    p.fecha_pago,
    p.total,
    p.id_transaccion
FROM cliente AS c
LEFT JOIN pago AS p
    ON c.pk_cliente = p.fk_cliente;

-- Verificación de la vista
SELECT *
FROM listado_pagos_clientes;
3. Crear la vista listado_pedidos_clientes. Mostrar todos los clientes y los pedidos que han realizado, incluyendo los clientes que no tienen pedidos.

Base de datos jardineria3

LEFT JOIN conserva a los clientes sin pedidos. Sus columnas de pedido contienen NULL.

MySQL 
CREATE OR REPLACE VIEW listado_pedidos_clientes AS
SELECT
    c.pk_cliente AS codigo_cliente,
    CONCAT(
        c.nombre_cliente, ' - ',
        c.nombre_contacto, ' ',
        c.apellido_contacto
    ) AS nombre_completo,
    c.telefono,
    c.ciudad,
    c.pais,
    p.pk_pedido AS codigo_pedido,
    p.fecha_pedido,
    p.fecha_esperada,
    p.fecha_entrega
FROM cliente AS c
LEFT JOIN pedido AS p
    ON c.pk_cliente = p.fk_cliente;

-- Verificación de la vista
SELECT *
FROM listado_pedidos_clientes;
4. Crear una variable de sesión denominada @ciudad. Mostrar los clientes de Madrid que han realizado pagos.

Base de datos jardineria3

SET asigna Madrid a la variable de la conexión. El filtro exige un identificador de transacción y DISTINCT elimina filas repetidas.

MySQL 
SET @ciudad = 'Madrid';

SELECT DISTINCT
    nombre_completo,
    telefono,
    ciudad,
    pais
FROM listado_pagos_clientes
WHERE ciudad = @ciudad
    AND id_transaccion IS NOT NULL;

Base de datos jardineria3

La misma consulta usa el valor Miami asignado con SET en la conexión activa.

SELECT DISTINCT

6.1. Empleados con más de 20 años de antigüedad.

Base de datos nomina3

TIMESTAMPDIFF calcula los años completos desde la fecha de contrato hasta CURDATE(). El filtro exige más de 20 años.

MySQL 
CREATE OR REPLACE VIEW empleados_antiguedad AS
SELECT
    e.nombre,
    e.apellido,
    d.departamento,
    e.fecha_contrato,
    TIMESTAMPDIFF(
        YEAR, e.fecha_contrato, CURDATE()
    ) AS antiguedad
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
WHERE TIMESTAMPDIFF(
    YEAR, e.fecha_contrato, CURDATE()
) > 20;

-- Verificación de la vista
SELECT *
FROM empleados_antiguedad;
6.2. Empleados solteros, divorciados o viudos con más de un hijo.

Base de datos nomina3

IN agrupa los tres estados civiles admitidos. El segundo filtro exige más de un hijo y TIMESTAMPDIFF calcula la edad.

MySQL 
CREATE OR REPLACE VIEW empleados_estado_civil_hijos AS
SELECT
    e.nombre,
    e.apellido,
    e.estado_civil,
    e.hijos,
    d.departamento,
    TIMESTAMPDIFF(
        YEAR, e.fecha_nacimiento, CURDATE()
    ) AS edad
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
WHERE e.estado_civil IN (
    'Soltero', 'Divorciado', 'Viudo'
)
    AND e.hijos > 1;

-- Verificación de la vista
SELECT *
FROM empleados_estado_civil_hijos;
6.3. Mostrar todos los cargos y sus empleados, incluyendo los cargos sin empleados.

Base de datos nomina3

LEFT JOIN conserva también los cargos que carecen de empleados. Sus columnas de empleado contienen NULL.

MySQL 
CREATE OR REPLACE VIEW cargos_empleados AS
SELECT
    c.cargo,
    e.nombre,
    e.apellido,
    TIMESTAMPDIFF(
        YEAR, e.fecha_nacimiento, CURDATE()
    ) AS edad,
    e.estado_civil
FROM cargo AS c
LEFT JOIN empleado AS e
    ON c.pk_cargo = e.fk_cargo;

-- Verificación de la vista
SELECT *
FROM cargos_empleados;
6.4. Mostrar los departamentos que no tienen empleados.

Base de datos nomina3

LEFT JOIN conserva todos los departamentos. IS NULL selecciona los que carecen de una fila de empleado asociada.

MySQL 
CREATE OR REPLACE VIEW departamentos_sin_empleados AS
SELECT
    d.pk_departamento,
    d.departamento
FROM departamento AS d
LEFT JOIN empleado AS e
    ON d.pk_departamento = e.fk_departamento
WHERE e.pk_empleado IS NULL;

-- Verificación de la vista
SELECT *
FROM departamentos_sin_empleados;
6.5. Mostrar los clientes que han realizado pagos y sus representantes de ventas.

Base de datos jardineria3

INNER JOIN requiere una coincidencia con el representante y con algún pago. DISTINCT evita repetir la misma pareja de cliente y representante por cada pago.

MySQL 
CREATE OR REPLACE VIEW clientes_con_pagos AS
SELECT DISTINCT
    c.nombre_cliente,
    CONCAT(
        e.nombre, ' ', e.apellido1
    ) AS representante
FROM cliente AS c
INNER JOIN empleado AS e
    ON c.fk_representante_ventas = e.pk_empleado
INNER JOIN pago AS p
    ON c.pk_cliente = p.fk_cliente;

-- Verificación de la vista
SELECT *
FROM clientes_con_pagos;

6.7. Mostrar los clientes que han realizado pagos, sus representantes y la ciudad de la oficina.

Base de datos jardineria3

La oficina se obtiene a partir del representante. Su ciudad aparece con el alias ciudad_oficina.

MySQL 
CREATE OR REPLACE VIEW clientes_con_pagos_oficina AS
SELECT DISTINCT
    c.nombre_cliente,
    CONCAT(
        e.nombre, ' ', e.apellido1
    ) AS representante,
    o.ciudad AS ciudad_oficina
FROM cliente AS c
INNER JOIN empleado AS e
    ON c.fk_representante_ventas = e.pk_empleado
INNER JOIN oficina AS o
    ON e.fk_oficina = o.pk_oficina
INNER JOIN pago AS p
    ON c.pk_cliente = p.fk_cliente;

-- Verificación de la vista
SELECT *
FROM clientes_con_pagos_oficina;

8. Crear una nueva tabla con el resultado de una vista basada en las consultas multitabla del ejercicio 9. Vista seleccionada: departamentos_sin_empleados.

Base de datos nomina3

La tabla almacena las filas disponibles en la vista al ejecutar la sentencia. DESCRIBE permite revisar sus columnas.

MySQL 
USE nomina3;

CREATE TABLE tabla_departamentos_sin_empleados AS
SELECT
    pk_departamento,
    departamento
FROM departamentos_sin_empleados;

-- Verificación de la tabla creada
SELECT *
FROM tabla_departamentos_sin_empleados;

-- Consultar la estructura de la nueva tabla
DESCRIBE tabla_departamentos_sin_empleados;
