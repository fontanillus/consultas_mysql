1. Crear una vista llamada vista_contactos mediante UNION utilizando las tablas cliente, empleado y oficina. Mostrar inicial, id, contacto, tipo y telefono. Ordenar por apellido.

Base de datos jardineria4

MySQL 
USE jardineria4;

CREATE OR REPLACE VIEW vista_contactos AS
SELECT
    inicial,
    id,
    contacto,
    tipo,
    telefono
FROM (
    SELECT
        LEFT(c.apellido_contacto, 1) AS inicial,
        LPAD(c.pk_cliente, 3, '0') AS id,
        CONCAT(c.nombre_contacto, ' ', c.apellido_contacto) AS contacto,
        'cliente' AS tipo,
        c.telefono,
        c.apellido_contacto AS apellido
    FROM cliente AS c

    UNION

    SELECT
        LEFT(e.apellido1, 1) AS inicial,
        LPAD(e.pk_empleado, 3, '0') AS id,
        CONCAT_WS(' ', e.nombre, e.apellido1, e.apellido2) AS contacto,
        'empleado' AS tipo,
        o.telefono,
        e.apellido1 AS apellido
    FROM empleado AS e
    INNER JOIN oficina AS o
        ON e.fk_oficina = o.pk_oficina
) AS contactos
ORDER BY apellido;

-- Verificar la vista

SELECT *
FROM vista_contactos;
2. Crear la vista clientes_morosos. Mostrar los códigos de clientes que tengan pedidos entregados y no hayan realizado pagos.

Base de datos jardineria4

MySQL 
CREATE OR REPLACE VIEW clientes_morosos AS
SELECT fk_cliente
FROM pedido
WHERE estado = 'Entregado'

EXCEPT

SELECT fk_cliente
FROM pago;

SELECT *
FROM clientes_morosos;
3. Utilizar la vista clientes_morosos junto con INNER JOIN para mostrar los datos de los clientes sin pagos.

Base de datos jardineria4

MySQL 
SELECT
    c.pk_cliente,
    c.nombre_contacto,
    c.apellido_contacto,
    c.telefono,
    c.ciudad
FROM cliente AS c
INNER JOIN clientes_morosos AS m   -- uso vista cliente_morosos
    ON c.pk_cliente = m.fk_cliente;
4. Repite los puntos 2 y 3 para tener la lista de clientes con pagos. Al generar la lista de clientes que hayan pagado (equivalente al punto 3) indica la fecha del pago y el importe.

Base de datos jardineria4

MySQL 
CREATE OR REPLACE VIEW clientes_con_pagos AS
SELECT fk_cliente
FROM pedido
WHERE estado = 'Entregado'

INTERSECT

SELECT fk_cliente
FROM pago;

-- Verificar la vista.

SELECT *
FROM clientes_con_pagos;

SELECT
    c.pk_cliente,
    c.nombre_contacto,
    c.apellido_contacto,
    c.telefono,
    c.ciudad,
    p.fecha_pago,
    p.total
FROM cliente AS c
INNER JOIN clientes_con_pagos AS v
    ON c.pk_cliente = v.fk_cliente
INNER JOIN pago AS p
    ON c.pk_cliente = p.fk_cliente;
