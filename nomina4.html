Ejercicios

Abre un enunciado para ver su solución.

1. Calcula el número total de empleados que hay en la tabla empleado.
MySQL 
SELECT COUNT(*) AS total_empleados
FROM empleado;
2. Calcula el número total de departamentos que hay en la tabla departamento.
MySQL 
SELECT
    COUNT(*) AS num_departamentos
FROM departamento;
3. Calcula la media de sueldo de todos los empleados.
MySQL 
SELECT AVG(sueldo) AS sueldo_promedio
FROM empleado;
4. Indica quién es el empleado más joven.
MySQL 
SELECT
    nombre,
    apellido
FROM empleado
WHERE fecha_nacimiento = (
    SELECT MAX(fecha_nacimiento)
    FROM empleado
);
5. Indica quién es el empleado menos joven.
MySQL 
SELECT
    nombre,
    apellido
FROM empleado
WHERE fecha_nacimiento = (
    SELECT MIN(fecha_nacimiento)
    FROM empleado
);
6. Calcula el número total de empleados por estado civil.
MySQL 
SELECT
    estado_civil,
    COUNT(*) AS total_empleados
FROM empleado
GROUP BY estado_civil;
7. Muestra el número de empleados que han ingresado cada año a la empresa.
MySQL 
SELECT
    YEAR(fecha_contrato) AS anio,
    COUNT(*) AS total_empleados
FROM empleado
GROUP BY YEAR(fecha_contrato);
8. Lista el nombre y el precio del producto más caro.
MySQL 
USE jardineria3;

SELECT
    nombre,
    precio_venta
FROM producto
WHERE precio_venta = (
    SELECT MAX(precio_venta)
    FROM producto
);
9. Calcula la suma de los salarios de los empleados por departamento.
MySQL 
SELECT
    d.departamento,
    SUM(e.sueldo) AS total_sueldos
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
GROUP BY d.departamento;
10. Calcula la suma de los salarios de los empleados por sexo.
MySQL 
SELECT
    sexo,
    SUM(sueldo) AS total_sueldos
FROM empleado
GROUP BY sexo;
11. Calcula el número de empleados que son Asistentes.
MySQL 
SELECT
    COUNT(*) AS total_empleados
FROM empleado AS e
INNER JOIN cargo AS c
    ON e.fk_cargo = c.pk_cargo
WHERE c.cargo = 'Asistente';
12. Calcula la media de hijos de los empleados por sexo y estado civil.
MySQL 
SELECT
    sexo,
    estado_civil,
    AVG(hijos) AS media_hijos
FROM empleado
GROUP BY sexo, estado_civil;
13. Calcula el sueldo más bajo de los Analistas.
MySQL 
SELECT
    MIN(e.sueldo) AS sueldo_menor
FROM empleado AS e
INNER JOIN cargo AS c
    ON e.fk_cargo = c.pk_cargo
WHERE c.cargo = 'Analista';
14. Calcula el sueldo más alto de los Analistas.
MySQL 
SELECT
    MAX(e.sueldo) AS sueldo_mayor
FROM empleado AS e
INNER JOIN cargo AS c
    ON e.fk_cargo = c.pk_cargo
WHERE c.cargo = 'Analista';
15. Muestra el sueldo máximo, sueldo mínimo, sueldo promedio y el número total de empleados por cargo.
MySQL 
SELECT
    c.cargo,
    MAX(e.sueldo) AS sueldo_mayor,
    MIN(e.sueldo) AS sueldo_menor,
    AVG(e.sueldo) AS sueldo_promedio,
    COUNT(*) AS total_empleados
FROM empleado AS e
INNER JOIN cargo AS c
    ON e.fk_cargo = c.pk_cargo
GROUP BY c.cargo;
16. Muestra el sueldo máximo, sueldo mínimo, sueldo promedio y el número total de empleados por departamento, ordenando de forma descendente por el sueldo promedio.
MySQL 
SELECT
    d.departamento,
    MAX(e.sueldo) AS sueldo_mayor,
    MIN(e.sueldo) AS sueldo_menor,
    AVG(e.sueldo) AS sueldo_promedio,
    COUNT(*) AS total_empleados
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
GROUP BY d.departamento
ORDER BY sueldo_promedio DESC;
17. Muestra la edad máxima, edad mínima, edad promedio y el número total de empleados de los departamentos que tienen una edad promedio superior a los 45 años.
MySQL 
SELECT
    d.departamento,
    MAX(TIMESTAMPDIFF(YEAR, e.fecha_nacimiento, CURDATE())) AS edad_maxima,
    MIN(TIMESTAMPDIFF(YEAR, e.fecha_nacimiento, CURDATE())) AS edad_minima,
    AVG(TIMESTAMPDIFF(YEAR, e.fecha_nacimiento, CURDATE())) AS edad_promedio,
    COUNT(*) AS total_empleados
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
GROUP BY d.departamento
HAVING edad_promedio > 45;
18. Calcula el número de empleados que tienen un sueldo mayor o igual a 1800€.
MySQL 
SELECT
    COUNT(*) AS total_empleados
FROM empleado
WHERE sueldo >= 1800;
19. Calcula el número de empleados que tienen una edad menor o igual a 28 años.
MySQL 
SELECT
    COUNT(*) AS total_empleados
FROM empleado AS e
WHERE (TIMESTAMPDIFF(YEAR, e.fecha_nacimiento, CURDATE())) <= 28;
20. Lista los nombres de los departamentos cuyos empleados tienen una edad promedio mayor o igual a 35 años.
MySQL 
SELECT
    d.departamento,
    AVG(TIMESTAMPDIFF(YEAR, e.fecha_nacimiento, CURDATE())) AS edad_promedio
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
GROUP BY d.departamento
HAVING edad_promedio >= 35;
21. Devuelve un listado con los nombres de los cargos que tienen 5 o más empleados.
MySQL 
SELECT
    c.cargo
FROM cargo AS c
INNER JOIN empleado AS e
    ON e.fk_cargo = c.pk_cargo
GROUP BY c.cargo
HAVING COUNT(*) >= 5;
22. Devuelve un listado con los nombres de los departamentos donde el promedio de edad sea superior a 40 años.
MySQL 
SELECT
    d.departamento,
    AVG(TIMESTAMPDIFF(YEAR, e.fecha_nacimiento, CURDATE())) AS edad_promedio
FROM empleado AS e
INNER JOIN departamento AS d
    ON e.fk_departamento = d.pk_departamento
GROUP BY d.departamento
HAVING edad_promedio > 40;
23. Muestra el número total de empleados que tiene cada departamento, incluyendo los departamentos que no tienen ningún empleado. El resultado mostrará dos columnas: nombre del departamento y número de empleados, ordenadas descendentemente por el número de empleados.
MySQL 
SELECT
    d.departamento,
    COUNT(e.pk_empleado) AS total_empleados
FROM departamento AS d
LEFT JOIN empleado AS e
    ON e.fk_departamento = d.pk_departamento
GROUP BY d.departamento
ORDER BY total_empleados DESC;
24. Explica las diferencias entre las cláusulas WHERE y HAVING, y cuándo utilizar cada una de ellas.

WHERE filtra registros individuales antes de la agrupación.

HAVING filtra los resultados agrupados después de la agrupación.
